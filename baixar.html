Baixar e instalar

Instale o SisDoc em poucos minutos

Um instalador só serve para todos os computadores da clínica. Ele já traz o programa e o banco de dados: não precisa instalar mais nada.

SisDoc para Windows

Última versão publicada

Windows 10 ou 11 64 bits cerca de 400 MB
Baixar o SisDoc

Já tem o SisDoc instalado? Não precisa baixar de novo: ele avisa e se atualiza sozinho. Veja as versões anteriores e o que mudou.

Requisitos mínimos

O computador principal guarda os dados de todos, por isso pede um pouco mais.

Memória4 GB (recomendado: 8 GB)4 GB
Espaço livre no disco5 GB, para o programa, o banco de dados e os backups1 GB
Tela1366 × 768 ou maior (funciona a partir de 1024 × 768)
RedeNa rede da clínica, de preferência por cabo, com IP fixoNa mesma rede do principal, com os mesmos números no começo do IP (cabo ou Wi-Fi)
Tipo de rede no WindowsPrivada. Em rede "Pública", os outros computadores não conseguem entrarQualquer uma
LigadoO dia todo e às 21:00, para o backupSó quando for usar
InternetSó para baixar o instalador e as atualizações. Para usar no dia a dia, não precisa

Para instalarUm usuário que possa dar permissão de administrador no Windows

Não funciona em Mac, Linux, celular ou tablet, nem em Windows de 32 bits. Tem um computador só? Ele é o principal e segue a primeira coluna. Com até uns 10 computadores na clínica, o principal dá conta com folga.

Antes de começar

Escolha o computador principal

É o que fica ligado o dia todo e guarda os dados. Normalmente, o da recepção.

  • Desligue a suspensão: Opções de energia → Nunca
  • Peça ao técnico um IP fixo para ele
  • Deixe a rede dele como Privada: Configurações → Rede e Internet → a rede em uso → Tipo de perfil de rede → Privada

Confira a rede e o acesso

Para instalar, o Windows pede permissão de administrador.

  • Todos os computadores na mesma rede, por exemplo todos em 192.168.0.x (o Wi-Fi de convidados não serve)
  • Vindo do SisDoc antigo? Tenha à mão o arquivo .mdb e a pasta Anexos
  • Chame o responsável pelo SisDoc: o instalador pede o e-mail e a senha de licença

No computador principal

Faça primeiro neste computador. Os outros vêm depois.

  1. Baixe e abra o instalador

    Clique em Baixar o SisDoc, espere o download terminar e abra o arquivo SisDoc-Setup-…exe, na pasta Downloads.

  2. Passe pelo aviso azul do Windows

    Se aparecer a tela "O Windows protegeu o computador", clique em Mais informações e depois em Executar assim mesmo. É normal: o aviso aparece porque o instalador ainda não tem o certificado pago de editor de software que o Windows reconhece. Para ter certeza de que o arquivo é o original, veja como conferir o instalador.

    Mais informações → Executar assim mesmo

    Depois, quando o Windows perguntar se o programa pode fazer alterações, clique em Sim.

  3. Digite a licença

    Na tela Licença do SisDoc, digite o e-mail e a senha de licença. Quem tem esses dados é o responsável pelo SisDoc: chame-o nessa hora. Assim o computador já fica ativado e o SisDoc abre direto.

  4. Escolha "Computador principal da clínica"

    Clique em Avançar até o fim e espere alguns minutos: a tela mostra as etapas 1 de 3, 2 de 3 e 3 de 3.

    Este computador já tinha o SisDoc? Escolha Usar o banco que já existe para continuar com os mesmos dados.

  5. Anote a senha do banco de dados

    Ela aparece no fim da instalação. Tire uma foto ou anote: os outros computadores vão precisar dela.

    Perdeu a senha? Ela fica em Menu Iniciar → SisDoc → SisDoc - Banco de dados, aba Estações.

  6. Comece do zero ou traga o SisDoc antigo

    Abra o SisDoc pelo ícone na área de trabalho.

    Começar do zero: crie o primeiro usuário, que será o administrador, e entre com ele.

    Importar do SisDoc antigo: escolha o arquivo .mdb e a pasta Anexos. Médicos, convênios, pacientes, consultas e prontuários vêm junto. No fim aparecem o usuário e a senha de um administrador novo: anote e entre com ele. Os usuários antigos entram como Recepção, com a senha de antes, e criam uma senha nova no primeiro acesso. Em "Olá, seu nome" → Acessos e senhas, mude para Médico quem for médico.

  7. Cadastre a clínica

    Os Primeiros passos abrem sozinhos e vão de etapa em etapa: os médicos (com a senha de assinatura de cada um), os horários de atendimento, os convênios (os mais comuns já vêm cadastrados) e o acesso da recepção. No fim, clique em Pronto! Ir para a agenda.

Nos outros computadores

Recepção, consultórios e qualquer outro computador da clínica. O computador principal precisa estar ligado.

  1. Abra o mesmo instalador

    Escolha Outro computador da clínica. Nesse modo, só o programa é instalado.

  2. Ative e conecte ao computador principal

    Abra o SisDoc, ative com o responsável e escolha Usar os dados do computador principal. O SisDoc procura o principal na rede e preenche o endereço sozinho.

    Não achou? Digite o nome do computador principal (ex.: RECEPCAO-PC ou \\RECEPCAO-PC) ou o IP dele (ex.: 192.168.0.10). Eles aparecem no principal, no SisDoc - Banco de dados, aba Estações.

  3. Digite a senha do banco

    A mesma que você anotou no computador principal. Clique em Conectar e entre com o usuário e a senha da pessoa.

Depois de instalar

Atualizações

Quando sai uma versão nova, o SisDoc avisa ao abrir. Clique em Atualizar agora e aceite a permissão do Windows: ele fecha, se atualiza e abre de novo. Os dados não mudam.

Atualize todos os computadores no mesmo dia, começando pelo principal.

Backup

O computador principal faz uma cópia dos dados todo dia às 21:00, em C:\ProgramData\SisDoc\Backups. Deixe-o ligado nesse horário.

Toda semana, copie essa pasta para um HD externo e guarde-o fora do computador principal. Os backups têm dados de pacientes: veja como protegê-los.

SisDoc - Banco de dados

Programa que vem junto, no Menu Iniciar. Mostra os dados para conectar os outros computadores, faz backup na hora, restaura um backup e troca de onde o SisDoc pega os dados, sem reinstalar.

Aprenda a usar

Aperte F1 em qualquer tela do SisDoc, ou leia o manual completo aqui no site.

Se algo der errado

As situações mais comuns e o que fazer em cada uma.

O que aconteceuO que fazer
O Windows mostrou uma tela azul e não deixou abrirClique em Mais informações e depois em Executar assim mesmo.
O instalador diz que o SisDoc está abertoFeche o SisDoc e clique em Avançar de novo.
O instalador diz que a porta 5432 já está em usoJá existe outro banco PostgreSQL no computador. Chame o responsável pelo SisDoc antes de instalar como computador principal.
A instalação do banco falhouConfira se há espaço no disco e se você aceitou a permissão de administrador. Mande ao responsável pelo SisDoc o arquivo %TEMP%\install-postgresql.log.
O outro computador não encontra o principalConfira se o principal está ligado, na mesma rede e com a rede do Windows como Privada (o SisDoc - Banco de dados avisa na aba Estações). Digite o nome ou o IP que aparecem no principal, no SisDoc - Banco de dados, aba Estações.
"A senha do banco de dados está errada"Pegue a senha no principal: Menu Iniciar → SisDoc → SisDoc - Banco de dados, aba Estações.
A agenda mostra "Falta cadastrar os médicos"Entre com um médico ou administrador e cadastre em "Olá, seu nome" → Médicos e convênios.
O aviso de versão nova não apareceConfira se o computador tem internet. As primeiras versões (as de teste e os instaladores da 2.0.0 gerados antes de 05/11/2026) precisam ser atualizadas à mão uma vez, baixando o instalador aqui.
"O computador principal ainda não aceita conexão criptografada"Atualize primeiro o SisDoc no computador principal e depois tente de novo neste.
"A atualização não tem a assinatura do responsável pelo SisDoc"O arquivo baixado não é o original e não foi instalado. Não instale à mão: chame o responsável pelo SisDoc.

Não resolveu? Chame o responsável pelo SisDoc e mostre o que apareceu na tela. Se puder, tire uma foto.
